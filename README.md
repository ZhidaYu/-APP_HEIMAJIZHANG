# 🐴 黑马记账

> 简单、直观的跨平台桌面记账应用 | 离线可用 · 无需登录 · 数据存本地

---

## 📖 简介

黑马记账是一款**跨平台桌面端个人记账应用**，支持 Windows 和 macOS。帮助你轻松记录每一笔支出和收入，通过直观的图表了解自己的消费习惯。

**核心理念**：你的数据只属于你 —— 所有数据存储在本地电脑，无需联网，无需注册账号。

---

## ✨ 功能特性

### 📝 记账功能
- **支出 / 收入双模式**：一键切换，记录支出或收入
- **二级分类体系**：10 个支出大类 + 5 个收入大类，40+ 个细分小类
- **自定义分类**：可自行新增、修改、删除分类（预置分类受保护，不可修改）
- **5 种支付方式**：微信支付、支付宝、银行卡、现金、其他
- **日期选择**：支持选择任意日期，默认当天
- **备注功能**：每笔记录最多 200 字备注

### 📋 账单管理
- **按日期分组**：账单按天分组显示，清晰直观
- **分类筛选**：支持一级 + 二级分类联动筛选，按支出/收入类型切换
- **编辑修改**：点击记录可弹窗编辑
- **删除确认**：删除前弹出确认框，防止误删
- **CSV 导入导出**：支持将数据导出为 CSV 文件，也可从 CSV 导入

### 📊 统计图表
- **月度概览**：月度总支出、日均支出、记账天数等概览卡片
- **分类饼图**：环形图展示各分类占比，一目了然
- **消费趋势**：折线图展示每日消费金额变化趋势
- **月份切换**：支持浏览不同月份的统计数据

### 🎨 界面体验
- **全中文界面**：所有文字使用简体中文
- **页面切换动画**：流畅的页面过渡效果
- **分类色彩体系**：每个分类有独立颜色标识
- **响应式布局**：适配不同屏幕尺寸

## 🚀 快速开始

### 环境要求

- **操作系统**：Windows 10/11 或 macOS 12+
- **Node.js**：版本 20+（推荐使用 Conda 管理）
- **Conda**（可选）：用于隔离管理 Node.js 环境

### 安装与运行

```bash
# 1. 克隆仓库
git clone git@github.com:ZhidaYu/-APP_HEIMAJIZHANG.git
cd 黑马记账\ APP

# 2. 激活 conda 环境（如果使用 Conda）
conda activate heima-accounting

# 3. 安装依赖
npm install

# 4. 启动开发模式（自动打开应用窗口）
npm run dev
```

### 打包发布

```bash
# 打包 Windows 安装程序（.exe）
npm run package:win

# 打包 macOS 安装程序（.dmg，需在 Mac 上操作）
npm run package:mac

# 打包全平台
npm run package:all
```

打包产物位于 `dist/` 目录下。当前 Windows 便携版约 74 MB，可直接运行无需安装。

## 📊 数据说明

### 存储方式
所有数据保存在本地的 SQLite 数据库文件中，位置为应用数据目录下的 `heima-accounting.db`。

### 金额精度
内部所有金额以**分**（整数）为单位计算，避免浮点数精度丢失。显示时自动转换为元（如 `3650` → `¥36.50`）。

### 日期格式
统一使用 `YYYY-MM-DD` 格式，界面显示为 `2026年08月07日`。

### 数据导出
支持导出为 CSV 格式，可用 Excel 或 WPS 打开。
