## 一、产品概述

### 1.1 产品定位

**黑马记账** 是一款面向普通用户的个人财务管理桌面应用。

- 🎯 **核心目标**：帮助用户轻松记录每一笔日常支出，了解钱花在了哪里
- 💻 **运行平台**：Windows 10/11 和 macOS 12+ 电脑
- 🌐 **使用方式**：完全离线，不需要注册账号，不需要联网
- 💰 **货币单位**：人民币（元），精确到分（如 36.50 元）
- 🀄 **界面语言**：全中文

### 1.2 产品口号

> 记一笔，只需 3 秒。

## 二、用户画像

| 用户类型 | 描述 | 核心需求 |
|---------|------|---------|
| **上班族小张**（25-35岁） | 月薪族，想搞清楚每个月钱花哪了 | 快速记账、按月看统计 |
| **学生小李**（18-24岁） | 生活费有限，需要精打细算 | 操作简单、分类清晰 |
| **自由职业老王**（30-45岁） | 收入不固定，需区分生活和工作支出 | 多维度筛选、数据导出 |

## 三、MVP 核心功能（第一版）

MVP = 最小可用版本，即第一个版本必须包含的功能。

| 编号 | 功能 | 说明 |
|------|------|------|
| F1 | **记一笔** | 添加一条支出记录：输入金额、选择分类、选择日期、填写备注 |
| F2 | **看账单** | 按时间倒序查看所有历史记录列表 |
| F3 | **改记录** | 修改或删除已有的记账记录 |
| F4 | **分类筛选** | 按一级或二级分类筛选查看账单 |
| F5 | **数据保存** | 所有数据存在电脑本地，关闭应用再打开数据不丢失 |

### 后续版本计划（不在第一版范围）

- 📥 数据导出为 Excel/CSV 文件
- ☁️ 云端备份与多设备同步

### 分类规则

- 所有支出分为 **一级分类**（大类）和 **二级分类**（小类）
- 记账时先选一级分类，再选对应的二级分类

## 七、界面设计思路

### 7.1 设计原则

- ⚡ **快**：打开 APP 就能记账，3 秒内完成一笔记录
- 🎯 **简**：界面清爽，没有多余按钮和信息
- 🔒 **安**：数据纯本地存储，不联网不上传
- ♿ **大**：字体和按钮适合各年龄层使用

### 7.2 主要页面

1. **记账首页**（默认打开页面）：金额输入 + 分类选择 + 记一笔按钮
2. **账单列表页**：所有历史记录，支持筛选
3. **统计页面**（后续版本）：图表展示消费分析

## 九、项目开发约定

> 以下约定将写入 CLAUDE.md，指导整个开发过程。

1. **所有技术决策由用户做出**：开发者必须列出方案 + 通俗解释 + 优缺点 → 用户选择 → 执行
